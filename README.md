## 👨‍💻 About Me

<img align="right" width="170" src="https://raw.githubusercontent.com/Chauhan2023/Chauhan2023/main/assets/coding.gif" />

I'm a **Full Stack / Backend Engineer** focused on building reliable, scalable and production-ready applications.

I work across the entire development lifecycle — from designing APIs and database architecture to building responsive interfaces, real-time systems and deploying applications to production.

### ⚡ What I Do

* 🧠 Design **backend architectures & secure APIs**
* 🚀 Build scalable applications with **Node.js, Express & Fastify**
* ⚡ Work with **Redis, RabbitMQ & WebSockets** for real-time systems
* 🗄️ Design and work with **PostgreSQL & MySQL**
* 🌐 Build modern interfaces using **React.js & Next.js**
* 📱 Develop cross-platform applications with **React Native**
* ☁️ Deploy and manage applications on **VPS / Cloud infrastructure**
* 🔧 Set up **Nginx, PM2, Cloudflare & CI/CD pipelines**
* 🤖 Use AI-assisted development with **Claude Code, Cursor & OpenCode**
